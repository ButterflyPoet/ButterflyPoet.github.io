# ButterflyPoet Engineering Portfolio — V1.1

Static bilingual personal portfolio for electronics and embedded systems. Built with plain HTML, CSS and JavaScript. No build tools needed.

## What changed in V1.1
- Shorter hero section and improved visual hierarchy
- Refined project cards, status labels and CSS-only illustrative covers
- Structured project-detail modal with four engineering sections
- Mobile spacing and keyboard-focus improvements
- Preserved bilingual, dark mode and category filters

## Deployment
Upload **the contents of this folder** to the root of `ButterflyPoet/ButterflyPoet.github.io` on the `main` branch. Replace matching files. GitHub Pages source remains `main` / `(root)`.

## Edit content
- `lang/zh.json`, `lang/en.json`: all translated labels, project descriptions and detail text.
- `assets/js/data.js`: project categories, tags, notes, timeline and skills.
- `assets/css/style.css`: colors, spacing and layout.
- `index.html`: page sections and links.

All sample projects are placeholders. Do not present them as completed work. Before publishing real projects, check intellectual-property rights, course policies and collaborators' permission.
